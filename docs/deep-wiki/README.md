## Evidence Standards

Every factual claim in this wiki carries an evidence label:

| Label | Meaning |
|-------|---------|
| **Proved** | Confirmed by at least one named, publicly accessible source (linked). |
| **Inferred** | Logically follows from proved facts but not directly stated in a public source. |
| **Needs&nbsp;confirmation** | Claimed or plausible but not yet verified against a public record. |

Claims labeled **Inferred** or **Needs confirmation** are never presented as
asserted fact. See
[Gaps To Close](./01-founders-proof-timeline.md#gaps-to-close-before-public-claims)
for the current list of unresolved items.
